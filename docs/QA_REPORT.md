## Открытые проверки / ограничения

- Полный новый pytest и независимый критический аудит: PASS в указанном ограниченном scope, не приёмка внешнего deploy или полного кейса.
- Основные browser-пути поиска/сценария/черновика/реального CSV/reload и desktop-снимки QORAI проверены ведущим. [Design QA](design-qa.md): узнаваемые структура/палитра/две колонки, видимых desktop-наложений нет; не pixel-perfect clone.
- Mobile NOT VERIFIED: попытка390×844 не изменила фактическую ширину браузера1218. Ведущий считает это остаточным риском, не блокером desktop-first MVP; проверку телефона/узкого viewport нельзя считать выполненной.
- Подготовка Python-хостинга и public-origin/TLS guard проверены локальными регрессионными тестами. Реальный внешний TLS/домен и процесс на хостинге не проверены; публичного URL пока нет.
- Реальная внешняя песочница, HTTPS/auth и публичный выпуск не проверены и не выполнялись.
- Dockerfile/.dockerignore/serve/инструкция подготовлены; Docker CLI отсутствует, поэтому build NOT RUN. Публичного URL нет. Host allowlist не является авторизацией и не гарантирует приватность опубликованных данных.
- Проверяется арифметика условного сценария, не истинность неизвестных бизнес-параметров. Нет доказанного улучшения спроса, stockout-компенсации или полного покрытия кейса.
