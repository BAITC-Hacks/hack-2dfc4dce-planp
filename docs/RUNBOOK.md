# QORAI — локальный запуск MVP

2026-09-23. Только ноутбук и конкурсный репозиторий; внешняя песочница/домен не настроены. Никакой публичной привязки без отдельного решения и защиты доступа.

1. Из корня репозитория: `py -m pip install -r requirements.txt`.
2. `py scripts/bootstrap_data.py --output-dir data/issued`, затем задать `HACKALEM_DATA_DIR` на эту папку либо уже имеющуюся `04_Excel` (IEK/Systeme electric,12 XLSX). Публичные архивы и все файлы сверяются по pinned SHA256; исходники не входят в Git.
3. `py -m uvicorn smartbuyer.app:app --host 127.0.0.1 --port 8765`.
4. Проверить `GET http://127.0.0.1:8765/api/health`, затем `/api/bootstrap`; открытие `/` требует готового `web/index.html`.
5. `py -m pytest -q` с теми же источниками. Пропуск из-за отсутствующих XLSX — не PASS данных.

Альтернативный переносимый запуск: `py -m smartbuyer.serve` (PORT из окружения, один worker, локальная привязка по умолчанию). Native Python закреплён `.python-version=3.13`. [DEPLOYMENT.md](DEPLOYMENT.md) описывает build-helper/внешний том, фактический домен и явный allowlist/PUBLIC_ORIGIN. Хостинг настраивает владелец; Sites отложен. Публичного URL, проверенной Docker-сборки и состоявшегося deploy сейчас нет.

Снимок читается лениво, дата берётся из источника (22.09.2026), не из часов компьютера. Reload перечитывает только настроенную папку. При ошибке старый исправный снимок сохраняется; при успехе расчёты для экспорта сбрасываются. Результаты живут в памяти одного процесса; после перезапуска их нужно рассчитать заново.

Остановка запуска в терминале: Ctrl+C. Если процесс запускался скрыто, сначала проверить PID/команду и привязку порта; останавливать только свой процесс, не произвольный сервер на8765. После итоговых127 тестов предыдущий собственный PID20500/launcher9660 проверен и остановлен; новый `smartbuyer.serve`: серверPID7492, launcher14556, bind127.0.0.1:8765. Health/bootstrap PASS:12 источников,3045 позиций,22.09.2026. PID относятся только к этому запуску и могут устареть. Логи — игнорируемые `outputs/api.stdout.log`, `outputs/api.stderr.log`.

Откат локального запуска: остановить свой процесс, запустить выбранную проверенную ревизию в отдельном чистом клоне с той же внешней папкой источников. Не делать reset/checkout поверх чужих правок. База данных отсутствует, исходные XLSX не изменяются, миграций нет.

CSV скачивается только по серверным result_id; никаких реальных заказов и проводок не выполняется. Нельзя использовать отчётный/сценарный остаток как подтверждённый live-склад. При неизвестных параметрах корректный исход — объяснимая блокировка.
